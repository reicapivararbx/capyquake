## Usage Notes

### Consistent Style Settings
- **Model recommendation:** Stable Diffusion XL, Midjourney v6, or DALL-E 3
- **Aspect ratios:** Use 16:9 for all images
- **Color palette:** Always reference #FF6600 (orange), #FFCC66 (gold), #0D0D0D (dark)
- **Theme:** Dark, atmospheric, 3D game aesthetic — never cartoon, never photographic
- **Character:** Capybara warriors, not cute animals — muscular, armed, combat-ready

### Post-Generation
1. Generate at native resolution or upscale
2. Add text overlays manually (titles, UI elements) if AI doesn't render them cleanly
3. Apply subtle orange color grading for consistency
4. Ensure all images share the same dark atmospheric tone
