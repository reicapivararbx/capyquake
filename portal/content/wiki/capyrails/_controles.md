# Controles — Capyrails

Os controles exatos podem variar conforme a build publicada. Em geral:

## Desktop

- **WASD** ou setas — movimento / câmera conforme o contexto
- **Mouse** — interação com UI e mundo
- **Espaço / E** — ações contextuais quando disponíveis

## Mobile

- Controles on-screen quando o build incluir suporte touch
- Prefira landscape em telas pequenas

## Problemas

Se o canvas não abrir, confira se os assets em `/capyrails/` carregam (HTTP 200) e se o console do navegador não reporta erros de módulo.
